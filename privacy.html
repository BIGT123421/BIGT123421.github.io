Privacy Policy

Effective date: 8 October 2026

Hazy is a personal AI assistant operated by Artin Hatami (Hatami Media), a video editor based in Norway. This policy explains how Hazy handles Google user data. Hazy is used only by Artin himself.

Who this applies to

Hazy is not offered to the public. The only Google account it connects to is Artin Hatami’s own account, and only with his permission.

Google data Hazy accesses, and why

With Artin’s permission, Hazy accesses his Gmail account for three things:

  • Read messages and related metadata, so Hazy can understand work requests and other mail he asks it to help with.
  • Label messages, so Hazy can organize that mail.
  • Create and edit drafts, so Hazy can prepare replies for Artin to review.

Hazy cannot send email. Sending, if Artin chooses to send a message, is done by him in Gmail.

Hazy does not access Google Drive, Google Sheets, Google Docs, or Google Calendar.

Where data is stored

Google user data that Hazy retrieves is stored locally on Artin’s own computer, his Mac. Hazy does not upload that data to a server for this app, and it does not keep a separate cloud copy. Data stays on his device.

No selling, sharing, or advertising

Hazy does not sell Google user data. It does not share Google user data with third parties. It does not use Google user data for advertising. Hazy runs only for Artin, on his own machine.

Limited Use

Hazy's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google API Services User Data Policy

Retention and deletion

Hazy keeps Google user data on Artin’s Mac only for as long as he wants it there to help manage his work. He can delete that local data at any time by removing it from his computer. Deleting local copies does not delete the original messages in Gmail.

If he stops using Hazy, he can remove the app and its local data from his Mac. No copy is kept on a Hazy server, because Hazy does not operate one.

Revoking access

Artin can revoke Hazy’s access to his Google account at any time at https://myaccount.google.com/permissions. After access is revoked, Hazy can no longer read, label, or create drafts in that account. Copies already stored on his Mac remain there until he deletes them.
